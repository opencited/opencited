# Design principles (OpenCited)

Agents working on UI should follow these in addition to root `AGENTS.md`.

## Components

- Use `@opencited/ui` for interactive and presentational primitives.
- Do not override colors, borders, or variants via `className` on UI components — add a `cva` variant in `packages/ui` instead.
- Allowed `className` tweaks: layout, spacing, sizing, typography scale (`text-sm`), interaction states.

## Loading and empty states

- Page/list/card loading: `<Skeleton>` arranged like the real content.
- Actions and inline status: `<Spinner>` with short descriptive text.
- Data fetching in the app: prefer `<QueryCell>` where the codebase already uses it.

## Deeper design work

For new surfaces or visual direction, use the **impeccable** skill (`/impeccable init`, `audit`, `polish`, etc.) and read `packages/ui/AGENTS.md` plus `apps/web/AGENTS.md`.
